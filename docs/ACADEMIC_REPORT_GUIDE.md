# Academic Report Guide

## Recommended chapter structure
1. Introduction and project context
2. Problem statement, aim, objectives, and research questions
3. Literature and existing-system review
4. Requirements analysis
5. Methodology and project management
6. System architecture and database design
7. Interface and accessibility design
8. Implementation
9. Security design
10. Testing and results
11. Evaluation against requirements
12. Limitations and future work
13. Conclusion

## Evaluation points
Discuss how integration reduces fragmented workflows; how the accessibility profile and filters support inclusive participation; how role-based control protects administrative actions; and why Firebase is more appropriate than direct database access from frontend JavaScript.

## Evidence to capture
Include screenshots of public pages, registration/login, member dashboard, filters, booking confirmation, freeze validation, cart/checkout, admin dashboard, accessibility modes, Firebase collections/rules, and representative test results.
