# User Manual

## Start the demonstration
1. Extract the ZIP file.
2. Open the project folder.
3. Double-click `index.html`.
4. Use a modern browser with JavaScript enabled.

## Member workflow
1. Choose **Register** and create an account.
2. Sign in from **Login**.
3. Use the member dashboard to edit your profile and select a membership.
4. Save accessibility preferences.
5. Browse **Sessions**, apply filters, and book an available session.
6. View or cancel bookings from **My Bookings**.
7. Submit a freeze request from **Freeze** when needed.
8. Browse **Products**, add items to the cart, and check out using payment at reception.
9. View orders under **Orders**.

## Administrator workflow
Use the demonstration administrator account:

- Email: `admin@mms.local`
- Password: `Admin123!`

The administrator can inspect members, bookings, sessions, orders, and freeze requests and update supported statuses.

## Accessibility controls
The floating controls provide larger text, dark mode, and high-contrast mode. Keyboard users can use Tab and Shift+Tab to move through controls and Enter or Space to activate buttons.

## Reset demonstration data
Clear the website's local storage in the browser's developer tools, or use a private/incognito window for a clean demonstration.
